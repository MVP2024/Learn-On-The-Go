# Платёжные системы в LearningPlatform

## Доступные платёжные системы

В проекте интегрированы **две платёжные системы**:

### 🇷🇺 ЮKassa (для России)
- **Лучший выбор для российских пользователей**
- Поддерживает российские карты
- Рубли (RUB) как основную валюту
- Подробная настройка: [YOOKASSA_SETUP.md](YOOKASSA_SETUP.md)
- Быстрый старт: [QUICK_START.md](QUICK_START.md)

### 🌍 Stripe (международная)
- **Лучший выбор для международных проектов**  
- Поддерживает множество валют
- Простая интеграция
- Подробная настройка: [STRIPE_SETUP.md](STRIPE_SETUP.md)

## Как выбрать платёжную систему

### Используйте ЮKassa если:
- ✅ Ваши пользователи в России
- ✅ Нужно принимать платежи в рублях
- ✅ Работаете с российскими банковскими картами

### Используйте Stripe если:
- ✅ Международная аудитория  
- ✅ Нужны множественные валюты
- ✅ Хотите более простую настройку
- ✅ Нужна лучшая документация и поддержка

## Настройка

### Для ЮKassa:
```env
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
YOOKASSA_TEST_MODE=True
```

### Для Stripe:
```env
STRIPE_PUBLISHABLE_KEY=pk_test_ваш_ключ
STRIPE_SECRET_KEY=sk_test_ваш_секретный_ключ
STRIPE_TEST_MODE=True
```

## Использование в API

При создании платежа указывайте нужную платёжную систему:

```json
{
    "payment_type": "discipline",
    "discipline_id": 1,
    "payment_method": "yookassa"
}
```

или

```json
{
    "payment_type": "discipline", 
    "discipline_id": 1,
    "payment_method": "stripe"
}
```

## Можно ли использовать обе системы одновременно?

**Да!** Система поддерживает работу с обеими платёжными системами одновременно. Пользователи могут выбирать удобный для них способ оплаты.

## Тестирование

Обе системы имеют тестовые режимы:

### ЮKassa тестовые карты:
- ✅ Успешная оплата: `5555555555554444`
- ❌ Отклонение: `4000000000000002`

### Stripe тестовые карты:
- ✅ Успешная оплата: `4242424242424242`
- ❌ Отклонение: `4000000000000002`
