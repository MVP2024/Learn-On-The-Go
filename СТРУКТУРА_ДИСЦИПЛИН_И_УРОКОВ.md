# 📚 Структура дисциплин и уроков в LearningPlatform

## 🎯 Как это работает

### 1. Дисциплины (предметы)
**Дисциплина** - это основной предмет, например "Математика", "Русский язык", "Программирование"

Поля дисциплины:
- `title` - Название дисциплины ("Математика")
- `display_order` - Порядок отображения в каталоге (1, 2, 3...)
- `description` - Описание дисциплины
- `owner` - Преподаватель, который ведёт дисциплину

### 2. Разделы дисциплины (опционально)
**Раздел** - это часть дисциплины, например "Глава 1. Алгебра", "Модуль 2. Геометрия"

Поля раздела:
- `title` - Название раздела ("Глава 1. Основы алгебры")
- `discipline` - К какой дисциплине относится
- `section_order` - Номер раздела в дисциплине (1, 2, 3...)

### 3. Уроки
**Урок** - это конкретный урок, например "Урок 1. Сложение чисел"

Поля урока:
- `title` - Название урока ("Сложение чисел")
- `discipline` - К какой дисциплине относится (обязательно)
- `section` - К какому разделу относится (необязательно)
- `lesson_order` - Номер урока в разделе или дисциплине (1, 2, 3...)
- `video_url` или `video_file` - Видео урока

## 📖 Примеры структуры

### Пример 1: Простая структура (без разделов)
```
📚 Дисциплина: "Математика" (display_order: 1)
   📝 Урок 1: "Сложение чисел" (lesson_order: 1)
   📝 Урок 2: "Вычитание чисел" (lesson_order: 2)
   📝 Урок 3: "Умножение чисел" (lesson_order: 3)
```

### Пример 2: Сложная структура (с разделами)
```
📚 Дисциплина: "Русский язык" (display_order: 2)
   📂 Раздел 1: "Части речи" (section_order: 1)
      📝 Урок 1: "Существительные" (lesson_order: 1)
      📝 Урок 2: "Прилагательные" (lesson_order: 2)
      📝 Урок 3: "Глаголы" (lesson_order: 3)
   
   📂 Раздел 2: "Синтаксис" (section_order: 2)
      📝 Урок 1: "Простые предложения" (lesson_order: 1)
      📝 Урок 2: "Сложные предложения" (lesson_order: 2)
```

### Пример 3: Смешанная структура
```
📚 Дисциплина: "Программирование" (display_order: 3)
   📝 Урок 1: "Введение в программирование" (lesson_order: 1, section: null)
   
   📂 Раздел 1: "Python основы" (section_order: 1)
      📝 Урок 2: "Переменные" (lesson_order: 2)
      📝 Урок 3: "Условия" (lesson_order: 3)
   
   📝 Урок 4: "Заключение" (lesson_order: 4, section: null)
```

## 🔧 Создание через API

### Создание дисциплины
```json
{
    "title": "Математика", 
    "description": "Основы математики для начинающих",
    "display_order": 1
}
```

### Создание раздела (опционально)
```json
{
    "title": "Глава 1. Основы алгебры",
    "discipline": "Математика",
    "section_order": 1
}
```

### Создание урока
```json
{
    "title": "Урок 1. Сложение чисел",
    "description": "Изучаем как складывать числа", 
    "discipline": "Математика",
    "section": null,
    "lesson_order": 1,
    "video_url": "https://rutube.ru/video/example/"
}
```

## 💡 Логика сортировки

### Дисциплины сортируются по:
1. `display_order` (порядок отображения)
2. `title` (название по алфавиту)

### Уроки сортируются по:
1. `discipline` (дисциплина)
2. `section` (раздел, если есть)
3. `lesson_order` (номер урока)

### Разделы сортируются по:
1. `section_order` (номер раздела)

## 🎮 Использование в админке

В Django Admin вы увидите:

1. **Дисциплины** - список всех предметов с порядком отображения
2. **Разделы дисциплин** - разделы, привязанные к дисциплинам  
3. **Уроки** - уроки с указанием дисциплины, раздела и номера

## 📱 Отображение для студентов

Студенты увидят структуру так:
1. Список дисциплин в порядке `display_order`
2. Внутри дисциплины - разделы в порядке `section_order`  
3. Внутри раздела - уроки в порядке `lesson_order`
4. Уроки без раздела показываются отдельно

Это даёт максимальную гибкость в организации учебного материала! 🎓
