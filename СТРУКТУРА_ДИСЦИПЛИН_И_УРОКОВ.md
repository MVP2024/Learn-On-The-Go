# Структура дисциплин и уроков

Кратко: как устроены дисциплины, разделы и уроки в платформе.

Структура
- Дисциплина (Discipline)
  - Может содержать разделы (Section) и/или уроки (Lesson)
- Раздел (Section)
  - Логическая группа уроков внутри дисциплины
  - Содержит уроки (Lesson)
- Урок (Lesson)
  - Принадлежит дисциплине, опционально — разделу
  - Порядок внутри раздела/дисциплины задаётся полем lesson_order

Поля (основные)
- Discipline: id, title, slug, description, owner, order/display_order
- Section: id, title, discipline_id, section_order
- Lesson: id, title, discipline_id, section_id (nullable), lesson_order, video_url/video_file, owner

Правила отображения и сортировки
- Дисциплины сортируются по полю order/display_order, затем по title.
- Разделы — по section_order.
- Уроки — по lesson_order внутри раздела; уроки без раздела показываются отдельно внутри дисциплины.

API: создание через сериализаторы
- Для создания урока поле discipline ожидает slug или числовой id. Рекомендуется использовать slug (slug-значение можно посмотреть через /api/disciplines/).

Примеры JSON для API
- Создать дисциплину:

```json
{
  "title": "Математика",
  "description": "Курс по математике",
  "display_order": 1
}
```

- Создать раздел:

```json
{
  "title": "Глава 1",
  "discipline": "matematika_7",
  "section_order": 1
}
```

- Создать урок:

```json
{
  "title": "Урок 1. Сложение",
  "description": "Базовые операции",
  "discipline": "matematika_7",
  "section": null,
  "lesson_order": 1,
  "video_url": "https://..."
}
```

Рекомендации
- Используйте slug для однозначной привязки discipline в API.
- Поддерживайте последовательность lesson_order и section_order целыми положительными числами.
- Если lesson.section не задан — урок будет отображаться в общем списке дисциплины.

Если нужно, добавлю mermaid‑диаграмму или примеры SQL/ORM запросов для построения структуры.
