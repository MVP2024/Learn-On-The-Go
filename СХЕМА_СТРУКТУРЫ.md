# Схема структуры дисциплин и уроков

Кратко: как устроены дисциплины, разделы и уроки в платформе.

Структура
- Дисциплина (Discipline)
  - Может содержать несколько разделов (Section)
  - Может содержать уроки напрямую (Lesson) — без раздела
- Раздел (Section)
  - Логическая группа уроков внутри дисциплины
  - Содержит уроки (Lesson)
- Урок (Lesson)
  - Принадлежит дисциплине, опционально — разделу
  - Порядок в разделе/дисциплине задаётся поле lesson_order

Пример (псевдографика):

Disciplina: "Русский язык"
- Раздел 1: "Части речи"
  - Урок 1: "Существительные"
  - Урок 2: "Прилагательные"
- Раздел 2: "Синтаксис"
  - Урок 1: "Простые предложения"
- Уроки без раздела:
  - Итоговая работа

Поля (в базе)
- Discipline: id, title, slug, description, owner, display/order
- Section: id, title, discipline_id, section_order
- Lesson: id, title, discipline_id, section_id (nullable), lesson_order, video_url/video_file, owner

Сортировка и показ в интерфейсе
- Дисциплины сортируются по order/display_order, затем по title
- Разделы — по section_order
- Уроки — по lesson_order внутри раздела; уроки без раздела показываются отдельно в дисциплине

Правила и рекомендации
- Для создания урока через API используйте поле `discipline` как slug или числовой id (LessonSerializer ожидает slug или id)
- Если lesson.section пустой — урок отображается в общем списке дисциплины
- lesson_order и section_order должны быть целыми положительными числами, чтобы правильно поддерживать порядок

Если нужно, могу сгенерировать простую диаграмму mermaid или дополнить этот файл примерами JSON для API (создание дисциплины / раздела / урока).
